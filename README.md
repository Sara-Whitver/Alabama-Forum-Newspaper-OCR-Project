# Alabama-Forum-Newspaper-OCR-Project
This repository contains the scripts and workflow for creating OCR for 20th century newspaper primary source materials, using the Alabama Forum Newspaper as a use case. 

The Alabama Forum Newspaper, published from 1981-2002, was the first and longest running LGBTQ newspaper in the state of Alabama. It is available in [The University of Alabama Libraries Digital Collections](https://digitalcollections.libraries.ua.edu/digital/collection/u0002_00000251). The paper was published in Birmingham, Alabama by Lambda, Inc. and editied by June Holloway.

As a use case, Alabama Forum presents a number of challenges for OCR, including non-standard formatting and typesetting, images, and non-standard white spaces and margins. In this project, I will explore a variety of strategies for establishing ground truth while training a local LLM to produce OCR with a high level of accuracy. This workflow is not novel or revolutionary; my motivation for this project is two-fold: 
    1. to learn to work with a local LLM to create OCR for printed primary source materials
    2. to provide a model and instructions for others who need to access accurate OCR for printed primary source materials but do not have experience or skills in doing so.
    
    This project is built by Sara Maurice Whitver as a research project and instructional demonstration for the Alabama Digital Humanities Center at The University of Alabama Libraries.
